# SkillsES · skills en español para Claude Code, Claude y Cowork

Skills pensadas para trabajar en España: fiscalidad, Administración, legal básico y negocio, con fuentes oficiales.

> Proyecto independiente. No está afiliado ni respaldado por Anthropic. Claude es una marca de Anthropic.

## Instalar (Claude Code)
```
claude plugin marketplace add CBGRStudios/skills-es
claude plugin install skills-es@skills-es
```
En Windows, en un solo paso (instala también Claude Code si no lo tienes):
```powershell
irm https://skillses.cbgrstudios.com/instalar.ps1 | iex
```

## Skills gratuitas
| Skill | Qué hace |
|---|---|
| `correo-formal-es` | Redacta y revisa correos de trabajo con el tono y las fórmulas que se usan en España: peticiones, reclamaciones, seguimientos, disculpas y negativas. |
| `presupuesto-es` | Genera presupuestos claros con IVA, retención de IRPF, condiciones de pago y validez, listos para enviar en Word o PDF. |
| `calendario-fiscal-es` | Te dice qué modelos de Hacienda te tocan según tu actividad y cuándo vencen, con recordatorios en tu calendario. |
| `boe-es` | Consulta el sumario diario y la legislación consolidada del BOE con la API oficial y cita el artículo exacto. |

## Pack Pro (9 €/mes)
- **Escritos a la Administración**: Redacta solicitudes, alegaciones y recursos de reposición o alzada con la estructura del artículo 66 de la Ley 39/2015.
- **Reclamaciones de consumo**: Escribe la reclamación a la empresa y, si no responde, la queja al organismo que toca: Banco de España, DGSFP, telecomunicaciones, AESA o consumo.
- **Contrato de prestación de servicios**: Borrador de contrato freelance con alcance, entregables, pagos, propiedad intelectual, confidencialidad y encargo de tratamiento RGPD.
- **Aviso legal, privacidad y cookies**: Borradores de aviso legal (LSSI), política de privacidad (RGPD) y de cookies para una web o tienda pequeña.
- **Propuestas comerciales**: Convierte unas notas en una propuesta profesional: contexto, solución, fases, precio, condiciones y siguientes pasos.
- **Análisis de pliegos de licitación**: Lee el PCAP y el PPT de un concurso público y te da requisitos de solvencia, criterios, fechas, riesgos y una lista de comprobación.
- **Comunidad de propietarios**: Convocatorias, actas y comunicados de junta con los requisitos de la Ley de Propiedad Horizontal.
- **CV y carta de presentación**: Adapta tu CV y tu carta a una oferta concreta, con el formato que esperan las empresas españolas y los filtros automáticos.
